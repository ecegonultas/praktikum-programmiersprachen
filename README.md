# Praktikum Programmiersprachen (Praktikum Informatik 1) – C++

Meine Lösungen zu den Versuchen 1–9 des Praktikums **Praktikum Informatik 1 – Einführung in die C++-Programmierung** (SoSe 2026, Institut für Mensch-Maschine-Interaktion, RWTH Aachen).
Im Bachelor Computer Engineering läuft die Veranstaltung als *Praktikum Programmiersprachen*.

Teile des Codes (z. B. Klassengerüste und Schnittstellen in Versuch 9) wurden vom Lehrstuhl vorgegeben. Die Implementierungen stammen von mir.

## Inhalt

| Versuch | Thema | Schwerpunkte |
|---|---|---|
| [01](Versuch01_Teil1) | Datenstrukturen und Operatoren | Variablen, Datentypen, `struct` |
| [02](Versuch02_Teil1) | Kontrollstrukturen, Referenzen, Zeiger und Funktionen | Fibonacci rekursiv und iterativ, Felder (Verschlüsselung) |
| [03](Versuch03) | Komplexere Projekte und Dokumentation | Othello mit einfacher KI, testgetriebene Entwicklung, Doxygen |
| [04](Versuch04) | Einführung in Klassen | Klasse `Vektor`, Rotationsmatrix, Konstruktoren, `const`-Methoden |
| [05](Versuch05) | Dynamische Datenstrukturen | Doppelt verkettete Liste, Studentendatenbank, Zeiger und dynamischer Speicher |
| [06](Versuch06) | Standard Template Library | `std::vector`, Datei-Ein-/Ausgabe (`ifstream`/`ofstream`) |
| [07](Versuch07) | Überladung | Operatorüberladung (`==`, `<`, `<<`), STL-Algorithmen (`std::sort`) |
| [08](Versuch08) | Vererbung und Polymorphie | Bücherei: abstrakte Basisklasse `Medium`, rein virtuelle Funktionen, `override`, späte Bindung |
| [09](Versuch09/Streetplanner) | GUI-Programmierung mit Qt | Streetplanner: Signals und Slots, Dialoge, Dijkstra-Algorithmus, Karte aus Datei einlesen (`QFileDialog`), Städteauswahl per `QComboBox` |
